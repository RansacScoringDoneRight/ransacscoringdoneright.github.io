RANSACScoringDoneRight.PrecomputedPair — Type
PrecomputedPair

Sorted squared residuals per model of one pool pair — the staging unit of stage_ig_shared_from_pairs: sorting once here makes every device sweep an O(n) linear scan over prefix sums.

RANSACScoringDoneRight.ScaleMarginal — Type
ScaleMarginal{K}(alpha0, beta0; outlier_halfwidth, t0 = nothing)

The scale-marginal spec of loss shape K at the IG prior (alpha0, beta0) on the squared loss width — e.g. one fit by type-II MLE (empirical Bayes), where beta0 is not tied to a prior centre. outlier_halfwidth bounds the density normalizer Z̃ (REQUIRED: it is the declared outlier support, POOL_FRAME_R_MAX in the pool frame's unit); t0 the centre of the log-scale domain, by default the prior mode log(beta0/(alpha0 + 1)) (or log((outlier_halfwidth/4)²) for an improper prior). THE one constructor of every family's spec: the keyword forms below only name the prior centre.

source
RANSACScoringDoneRight.SmoothTLSMarginal — Type
SmoothTLSMarginal(; alpha0=1.0, prior_loss_width, outlier_halfwidth)

Marginal smooth-TLS scoring spec. prior_loss_width is the IG-prior centre on the smooth-TLS loss width (beta0 = alpha0·prior_loss_width² ⇒ 2·alpha0 pseudo-observations at pseudo-squared-width prior_loss_width²); outlier_halfwidth bounds the density normalizer Z̃ (set to POOL_FRAME_R_MAX, the declared outlier support in the pool frame's unit — required, no default). alpha0/beta0 match IGPrior, as for WelschMarginal. The evidence is the trapezoid scale quadrature of loss_spec(::ScaleMarginal).

RANSACScoringDoneRight._build_score_weight_matrix — Function
_build_score_weight_matrix(scoring, loss_widths, N_bins, d2_min, d2_max)
    -> Matrix{Float32}  size (N_bins, T)

Precompute W[bin, t] = residual_quality(scoring, d²_bin, loss_width_t) on the host at the bin centres of a log-spaced grid. The centres are d²_bin = d²_min · (d²_max/d²_min)^((bin-0.5)/N_bins), and W holds the SAME scalar quality Core's exact kernel evaluates per residual. Returned column-major so the kernel can index W[bin + (t-1)·N_bins].
